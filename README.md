# Deepal HU Translate — перевод ГУ на русский (Deepal S05)

Русский перевод головного устройства (ГУ) **Deepal / Changan S05** (прошивка 3.2.0).

Перевод сделан в виде **RRO-оверлеев** — устанавливаются APK, которые
«накладывают» русские строки поверх китайских в приложениях ГУ.
Сама прошивка **не меняется** — перевод можно снять в любой момент,
ГУ вернётся в исходное состояние.

Два варианта установки (выберите один):

- **Динамические RRO** (`apks_rro_min/`) — ставятся как обычное приложение,
  их можно включать, отключать и удалять; root-раздел не нужен.
- **Статические RRO** (`apks_rro_static/`) — кладутся в системный раздел
  `/vendor/overlay`, активны с загрузки, «зафиксированы»
  (снятие = удаление + перезагрузка).

## Установка — 3 шага

1. **Скачайте** и распакуйте последний релиз
   ([Releases](https://github.com/free4fan/deepal-HU-translate-3.2.0/releases)).
   Внутри: `apks_rro_min/`, `apks_rro_static/`, `deepl` (или `deepl.exe`),
   `targets.txt`, `README.md`.
2. **Подключите ГУ к компьютеру** по USB и включите ADB
   (инженерное меню ГУ). Если устройство не подхватилось —
   пункт `[R]` в меню ниже.
3. **Запустите `deepl` из этой папки** (Windows — `deepl.exe`):
   - `[1] Установить + включить` → выберите, что ставить:
     `8` — TOP-8 (быстрый чек), `A` — все группы, `[L]` — поштучно по номерам.
   - Готово. Русский проявляется после перезапуска приложений
     (закрыть из «недавних») или после перезагрузки ГУ.

**Статический вариант** — то же самое, только меню от `./deepl stat`:
установка = копирование в `/vendor/overlay` (root+remount делается сам),
после установки — перезагрузка ГУ (`adb reboot` или пункт меню).

Подробности (все пункты меню, команды руками, проверка, снятие) —
→ **[docs/INSTALL.md](docs/INSTALL.md)**

## Как вернуть всё как было

Всё снимается тем же меню `deepl`:

- **Динамические:** `[3] Отключить`, `[4] Удалить`.
- **Статические:** `[2] Удалить` + перезагрузка.
- **Возврат языка системы:** при установке перевод выставлял
  `system_locales = ru-RU,en-US,zh-CN`. Пункт меню **`[9] Восстановить
  оригинальную локаль`** возвращает `zh-CN` (как из коробки).
  Оверлеи при этом не удаляются — для них пункты `[3]`/`[4]`/`[2]`.

## Если что-то не работает

- `[5] Статус` — что установлено и что включено.
- `[6] Диагностика`, `[7] Собрать логи` — zip-отчёт для анализа.
- `shot.exe -q "фраза_на_китайском" -d 120` — охота за фразами, которых
  нет в APK (runtime: сцены, TTS, ASR); `-cjk` — все китайские фрагменты.
- ADB не видит ГУ: `[R] Проверить ADB заново` в меню; подробное —
  в [docs/INSTALL.md](docs/INSTALL.md).
